# Screenshot capture guide

Capture these screens from the running Streamlit application using realistic, non-sensitive demonstration data. Do not use fabricated results or real recipient addresses.

| # | Screen | Suggested capture |
|---|---|---|
| 1 | Dashboard | Open **Dashboard** after saving two or three draft applications. |
| 2 | Matching | Analyze a Data Engineer PFE offer and show score, keywords, explanation, and CV recommendation. |
| 3 | Email | Open **Générateurs > Email**, generate an English or French draft, and show the editable subject/body. |
| 4 | Motivation letter | Generate a letter, show the editable text, then open the downloaded PDF in a PDF viewer. |
| 5 | CSV | Upload `data/imports/offres_pfe.csv` and show validation metrics plus the preview table. |
| 6 | Gmail | With OAuth configured, show connection status, retrieved message list, and a reviewed message body. |
| 7 | Tracking | Open **Suivi**, filter by status, select a row, and show a status update. |
| 8 | Architecture | Capture the Mermaid architecture diagram from the README or a rendered project diagram. |

For a clean demonstration, use a fresh local database, hide browser personal data, and do not click any send button unless the recipient is a test account and the confirmation is intentional.
